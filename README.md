# CINEMOD

CINEMOD is a modern React movie app built with the TMDB API.
The app lets users discover movies, explore cast and recommendations, save favourites, build a personal watch list, and switch between light and dark themes.
<img width="1872" height="828" alt="image" src="https://github.com/user-attachments/assets/f18158b4-e0b9-4dfd-8b94-576cfca54af9" />

## What you can do
- Browse Discover, Popular, Top Rated, Now Playing and Upcoming movies
- Open detailed movie pages with cast, reviews and recommendations
- View actor details
- Add movies to Favorites and My List
- Search movies by title
- Filter by genre, rating and year
- Sort movies by rating, date or title
- Browse movies with pagination
- Switch between light and dark themes
- Enjoy animated purple background effects in dark mode

## Main technologies

React, Vite, Material UI, React Router, React Query and TMDB API

## Run the project

```bash
npm install
npm run dev
```

Create a `.env` file and add:

```text
VITE_TMDB_KEY=your_tmdb_api_key
```
